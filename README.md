# SDLC Project – Clicker Game + Accounts

## What this system is
A simple web-based clicking game where users can create an account, log in, and save their score/upgrade info to a database.

## Who it is for
People who want a quick game to play when they’re bored (students, anyone killing time).

## What problem it solves
It gives you something fun to do fast, and it saves your progress so you don’t lose your score.

---

## Must-have requirements (from assignment)
- User authentication (login system)
- Web form connected to a database (store + retrieve data)
- Security best practices (password hashing, encryption for sensitive data)
- Help documentation (PDF mockup is fine)

---

## Scope (what we will / won’t do)
**Will do:**
- Register + login/logout
- Click-to-earn points
- Save score to database
- Show leaderboard (basic)

**Won’t do:**
- Mobile app
- Payments
- Social media login
- Complex anti-cheat (basic protections only)
