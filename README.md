# SDLC Group Project

## Project Overview
Our project is a **Favorite Links Storage System**.  
It is a simple web-based application that allows users to create an account, log in, and securely save and manage their favorite website links.

## Who It Is For
This system is for **students, professionals, or anyone** who wants a simple and secure way to store important links in one place instead of relying on bookmarks across different devices.

## What Problem It Solves
People often lose important links or have them scattered across browsers and devices.  
This system solves that by providing a **centralized, secure location** where users can store and retrieve their favorite links anytime after logging in.

## Core Features
- User authentication (login & registration)
- Web form to add and retrieve saved links
- Data stored in a database
- Password hashing and basic security best practices
- Help documentation (PDF or mockup)
